03

Fases del plan · Lo más importante

6 fases · 45 días · prioridades no negociables

Fase 0–1 · Cimientos + SQL (Días 1–7)

Diagnóstico, CV maestro, LinkedIn base y SQL hasta window functions.

⚠️ Lo más importante: SQL es lo primero que evalúan. Domina CTEs y window functions antes que cualquier otra cosa. Postula desde el día 1, no esperes estar “listo”.

Fase 1–2 · Proyecto I + Python (Días 8–14)

Primer proyecto público y Python/Pandas operativo.

⚠️ Lo más importante: un proyecto publicado con README vale más que diez cursos. Pandas se aprende limpiando datos reales.

Fase 2–3 · Proyecto II + Power BI (Días 15–21)

EDA documentado, Power BI, DAX y el dashboard estrella.

⚠️ Lo más importante: Power BI + DAX (CALCULATE) es el combo más pedido en CR. Cada medida documentada con la decisión que habilita.

Fase 3–4 · Estadística + Marca (Días 22–28)

Estadística aplicada, storytelling, CV v2, networking y contenido.

⚠️ Lo más importante: la estadística se pregunta en entrevistas (correlación, A/B). Networking: relación antes que transacción. 8 historias STAR listas.

Fase 4–5 · Búsqueda intensiva (Días 29–35)

20 postulaciones + 15 contactos + 3 mocks de entrevista.

⚠️ Lo más importante: volumen con calidad: vacantes A personalizadas primero. Las simuladas grabadas duplican tu nivel en entrevistas reales.

Fase 5–6 · Entrevistas + Cierre (Días 36–45)

Entrevistas reales/simuladas, negociación, embudo y plan siguiente.

⚠️ Lo más importante: el embudo manda: ajusta con datos qué canal y CV funcionan. Negocia siempre. El plan no termina: se reinicia mejor.
